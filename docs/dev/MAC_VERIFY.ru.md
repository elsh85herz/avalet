# Проверка на Маке перед релизом (около 15 минут)

Что облачная сессия не могла прогнать: настоящий микрофон и системный звук,
разрешения macOS, распознавание текста Apple Vision, встроенный Python venv,
настоящую загрузку модели речи и сам `.dmg`. Прогони это на Маке с `.dmg` из
воркфлоу "Release (macOS)" (вкладка Actions, последний прогон, артефакт
`avalet-macos-arm64` или `avalet-macos-x64`).

Перед началом: тестовый звонок в Zoom/Meet/Телемосте или видео на YouTube с
речью, наушники по желанию, а для шага 8 — биллинг-сервер, запущенный
командой `npm run mock:server` в клоне репозитория (выведет `url` и
`publicKey`).

Отмечай каждый пункт, "Ожидается" — что должно произойти.

## 0. Запуск с нуля, без .dmg (не из MAC_VERIFY.md, добавлено отдельно)

Если тестируешь не `.dmg`, а локальную сборку через `npm run update:mac`,
и хочешь оценить приложение как новый пользователь — не трогай реальную
папку данных, а запусти с изолированной:

```bash
AVALET_USER_DATA_DIR="$HOME/avalet-fresh-test/userdata" \
HF_HOME="$HOME/avalet-fresh-test/hf-cache" \
/Applications/Avalet.app/Contents/MacOS/Avalet
```

Настоящие настройки, ключи, история встреч и уже скачанная модель речи
остаются нетронутыми — мастер запустится с шага 1, как у нового
пользователя, и шаг 5 (загрузка модели) отработает по-настоящему.
Если модель качать заново не хочешь — убери строку с `HF_HOME`, тогда
возьмётся уже скачанная модель из настоящего кэша, а настройки и история
всё равно будут пустыми.

С `.dmg` пункты 1-2 ниже актуальны как есть (диалог Gatekeeper); с локальной
сборкой через `update:mac` файл не в карантине — сразу открывается мастер,
начинай с пункта 3.
